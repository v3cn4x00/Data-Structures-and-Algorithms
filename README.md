# Data Structures and Algorithms in C++

My learning repository for **Data Structures and Algorithms**, implemented in C++. It documents my progress through practical examples and step-by-step implementations.

## Topics

- **Sorting:** Bubble Sort and Selection Sort
- **Linked Lists:** Singly Linked Lists, insertion, deletion, and traversal
- **Number Systems:** Binary, Decimal, and Hexadecimal conversions
- **Core Concepts:** Pointers, dynamic memory allocation, and time complexity

More topics will be added as I progress.

## Learning Goals

- Understand how each data structure works.
- Implement algorithms from scratch.
- Compare algorithm efficiency through comparisons, swaps, and complexity.
- Practice memory management and pointer manipulation.

## Running the Code

Compile an individual source file using a C++ compiler:

```bash
g++ -std=c++17 filename.cpp -o program
```

Run on Linux or macOS:

```bash
./program
```

Run in Windows PowerShell:

```powershell
.\program.exe
```

Replace `filename.cpp` with the source file you want to run. Compile files containing their own `main()` function separately.
